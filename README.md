# Мандарин 🍊

Конвертер файлов для macOS в духе Tangerine: начните тащить файл, зажмите **⇧ Shift** — вокруг курсора появится колесо. Бросьте файл на нужный сектор, и результат появится рядом с оригиналом.

- **Внутреннее кольцо** — форматы (JPG, PNG, HEIC, PDF, DOCX, MP3…)
- **Внешнее кольцо** — инструменты (сжать, обрезать, убрать фон, повернуть, распознать текст…)
- **Центр** — отмена

| Файл | Форматы | Инструменты |
|---|---|---|
| Картинки | JPG, PNG, HEIC, PDF, TIFF | сжать, ½ размера, убрать фон, обрезать, фон-рамка, повернуть, Ч/Б, текст (OCR) |
| PDF | DOCX, TXT, RTF, JPG, PNG | сжать, разделить, повернуть, текст, объединить |
| Документы | PDF, DOCX, TXT, RTF, HTML | — |
| Видео | MP4, MOV, GIF, MP3, M4A | сжать, без звука, кадр |
| Аудио | MP3, M4A, WAV, AIFF, FLAC | — |

Без перетаскивания: иконка в строке меню → «Выбрать файлы…».

## Сборка

Нужны macOS 15+ и Xcode. Для видео и аудио желателен `ffmpeg` (`brew install ffmpeg`).

```bash
./build.sh
```

Скрипт собирает `Mandarin.app`, ставит его в `/Applications` и запускает.
